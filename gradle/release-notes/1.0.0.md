# HC Autopsy 1.0.0

Initial HC Autopsy release candidate for Fabric servers.

- Supports Minecraft `1.20` through `1.21.11` with one compatibility-group jar.
- Supports Minecraft `26.1`, `26.1.1`, `26.1.2`, and `26.2-pre-3` with one
  `26.x` compatibility-group jar.
- Tracks Hardcore run wipes on the server.
- Captures player stat snapshots and run metadata.
- Provides `/hcautopsy` commands for run history and totals.
- Supports optional Discord webhook notifications.
- Includes the final HC Autopsy mod icon.
