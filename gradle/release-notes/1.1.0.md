HC Autopsy 1.1.0 hardens wipe recording and adds more in-game review tools.

## Highlights

- Wipe stat capture now honors `statSaveDelayMs` and waits for server-thread stat
  saves before reading vanilla stat JSON.
- Continuing a wiped run is blocked while the wipe is still finalizing, avoiding
  lifetime-total races.
- Config, metadata, snapshots, aggregates, and lifetime totals now write through
  atomic file replacement.
- Malformed config and run metadata are handled more defensively.
- Discord notifications now respect `discordNotificationsEnabled`.
- HC Autopsy now keeps a cached player-name index for offline player total
  lookup and command suggestions.
- Added `/hcautopsy players`.
- Added `/hcautopsy leaderboard playtime`, `deaths`, `walked`, and `jumps`.
- Added `/hcautopsy recalc`, `/hcautopsy config reload`, and
  `/hcautopsy discord test`.
- After a wipe finishes snapshotting, online players receive an in-game summary
  with run duration, snapshot count, total playtime, deaths, and top playtime.

This is an additive release. Existing `config/hc-autopsy/` data remains
compatible.
